# การเพิ่มข่าวผ่านแชท Claude (ระบบหลังบ้าน)

เว็บนี้ไม่มีหน้า admin ให้ส่งข่าวให้ Claude ในแชทแทน แล้ว Claude จะเขียน แปล build และ push ขึ้นเว็บให้

## สิ่งที่ส่งมาในแชท

ส่งอย่างน้อยหนึ่งอย่างต่อไปนี้:

- ลิงก์ข่าวต้นทาง (ข่าวทางการหรือสำนักข่าว)
- หรือเนื้อหา / ประเด็นข่าวเป็นภาษาไทยหรืออังกฤษ
- (ถ้ามี) รูปประกอบ, หมวด, ความสำคัญ (ทั่วไป / สำคัญ / ด่วน)

ตัวอย่าง: “เพิ่มข่าว: ตม. เปิดให้รายงานตัว 90 วันในแอป THIM แล้ว ลิงก์ ... ความสำคัญ: สำคัญ”

## สิ่งที่ Claude จะทำ

1. ตรวจข้อเท็จจริงกับแหล่งข้อมูลอย่างน้อยหนึ่งแห่ง และแจ้งถ้าข้อมูลขัดแย้งกัน
2. เขียนข่าวภาษาอังกฤษเป็นต้นฉบับที่ `src/content/news/en/<slug>.md` พร้อม frontmatter
   (`category`, `severity`, `publishedAt`, `affects`, `sources`, และ `image` ถ้ามี)
3. แปลครบ 10 ภาษาไว้ที่ `src/content/news/<lang>/<slug>.md` (nl, de, sv, fi, no, fr, da, th, zh, ru)
   โดยไฟล์แปลมีแค่ `title`, `summary`, `affects` และเนื้อหา ข้อมูลอื่นดึงจากไฟล์อังกฤษ
4. ถ้าข่าวทำให้คู่มือล้าสมัย จะแก้คู่มือที่เกี่ยวข้องและเปลี่ยน `lastChecked`
5. รัน `npm run build` ให้ผ่าน แล้ว commit และ push ขึ้น `main` จากนั้น Netlify จะเผยแพร่ภายในไม่กี่นาที

ข่าวล่าสุดจะขึ้นเป็น "ข่าวเด่น" ในมุมข่าวหน้าแรกโดยอัตโนมัติ (เรียงตาม `publishedAt`)

## รูปประกอบข่าว

วางไฟล์รูปไว้ที่ `src/content/news/images/` แล้วใส่ใน frontmatter ของไฟล์อังกฤษ:

```yaml
image: ../images/thim-app.jpg
imageAlt: หน้าจอแอป THIM
```

Astro จะย่อขนาดและแปลงเป็น WebP ให้อัตโนมัติ ถ้าไม่มีรูป มุมข่าวจะแสดงโลโก้แทน

## แก้ไขหรือลบข่าว

- **แก้ไข:** บอก Claude ว่าจะแก้อะไร ระบบจะใส่ `updatedAt` และแก้ทุกภาษา
- **ลบ:** ลบไฟล์ `<slug>.md` ในทุกโฟลเดอร์ภาษา

## ถ้าแปลไม่ครบ

ถ้าภาษาไหนยังไม่มีไฟล์แปล หน้านั้นจะแสดงเนื้อหาภาษาอังกฤษพร้อมแถบแจ้งเตือน และตั้ง `noindex` เพื่อไม่ให้ Google เห็นเป็นเนื้อหาซ้ำ
